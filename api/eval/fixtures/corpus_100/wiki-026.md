# 互联网

互联网 是20世紀末期興起電腦網路與電腦網路之間所串連成的龐大網路系統。這些網路以一些標準的網路協議相連。它是由從地方到全球範圍內幾百萬個私人、學術界、企業和政府的網路所構成，透過電子、無線和光纖網絡技術等等一系列廣泛的技術聯繫在一起。互聯網承載範圍廣泛的信息資源和服務，比方說相互關聯的超文本文件，還有萬維網（WWW）的應用、電子郵件、通話，以及文件共享等個人收發服務。
