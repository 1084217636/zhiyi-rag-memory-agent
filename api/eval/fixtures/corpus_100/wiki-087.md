# 戰爭與和平

《戰爭與和平》 是俄國作家列夫·托爾斯泰的一部长篇小说，講述拿破崙戰爭時期的俄羅斯。早期版本的部分内容名为《1805 年》，于1865 年至 1867 年在《俄罗斯信使》上连载。小说全文后于 1869 年完整出版。它将虚构叙事与历史和哲学章节相融合，被认为是托尔斯泰最杰出的文学成就，至今仍是享誉国际的世界文学经典之一。
