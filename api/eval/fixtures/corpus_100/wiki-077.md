# 鐵路運輸

鐵路運輸，通稱轨道交通，是指利用車輛在固定軌道（通常由兩條平行鋼軌組成）上行駛的陸路運輸方式，用以載運旅客和貨物。鐵路系統的核心技術優勢在於具備較高的能源效益、規模經濟與速度潛力，承擔了全球約8%的旅客和貨物輸送量。雖然鐵路建設和維護成本較高，但由於其軌道能有效分散列車重量，使單次載運量遠超一般道路車輛；同時，車輪與軌道之間的滾動摩擦阻力遠低於橡膠輪胎與路面，這容許多節車廂得以連結成較大的列車編組，實現高效率的長途運輸和規模經濟效益。
