# 第一次工业革命

第一次工業革命 和20世紀以来的第三次工業革命。在此期間，人類生產與製造方式逐漸轉為機械化，出現以机器取代人力、畜力的趨勢，以大规模的工廠生产取代手工生产的革命，引發自現代的科學革命。由於機器的發明及運用成為了這個時代的標誌，史學家便稱這個時代為機器時代。
