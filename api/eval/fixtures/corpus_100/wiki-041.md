# 撒哈拉沙漠

撒哈拉沙漠 位於非洲大陸北部，是世界最热的荒漠，亦是世界第三大荒漠，仅次于南极和北极，同时也是世界上最大的沙漠，其总面积超过9,400,000平方公里（3,600,000平方英里），与美国国土面积相当。撒哈拉沙漠东至红海（包括地中海海岸的一部分），西至大西洋，南部边界则为萨赫勒和撒哈拉以南非洲中部和西部的北端地区。撒哈拉沙漠中的一些沙丘高度可达180米（590英尺）。“撒哈拉”为阿拉伯语中“沙漠” 一词的复数形式。
