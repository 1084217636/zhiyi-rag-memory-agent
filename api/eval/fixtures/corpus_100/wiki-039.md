# 喜马拉雅山脉

喜马拉雅山脉 是世界海拔最高的山脉，分布于青藏高原南缘，处于中國西藏自治区与巴基斯坦、印度、尼泊尔、不丹等国边境上。由大喜马拉雅山脉、小喜馬拉雅（也称下喜馬拉雅）及外喜马拉雅（也称亚喜马拉雅或西瓦利克山脈）等数条大致平行的支脉组成，南凸呈弧形，东西长约2500多公里，南北宽200-300公里。
