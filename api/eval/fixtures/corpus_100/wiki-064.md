# 糖尿病

糖尿病 是以持續性高血糖為特點的代谢性疾病。患者的胰脏无法製造出足夠的胰岛素，或身體細胞對胰島素欠反應，引起統稱為「三多一少」的症狀—— 多尿、多渴、多食、體重減少。未經妥善控制的糖尿病可導致心血管病变、视网膜病变、 腎病变、周邊神經病變等多種併發症。每年造成約340萬人死亡，當中約160萬例可直接歸因於未經妥善控制的糖尿病。
