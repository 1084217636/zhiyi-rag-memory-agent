# 脱氧核糖核酸

脱氧核糖核酸 是一種生物大分子，可組成遺傳指令，引導生物發育與生命機能運作。主要功能是資訊儲存，可比喻為「藍圖」或「配方」。其中包含的指令，是建構細胞內其他的化合物，如蛋白質與核醣核酸所需。帶有蛋白質編碼的DNA片段稱為基因。其他的DNA序列，有些直接以本身構造發揮作用，有些則參與調控遺傳訊息的表現。
