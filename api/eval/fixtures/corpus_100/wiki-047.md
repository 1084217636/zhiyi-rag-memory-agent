# 地球

地球是太阳系中由內向外的第三顆行星，与太阳平均距离149,597,870公里（1天文單位），位于太阳系宜居带正中位置。地球质量约为5.972×1024公斤，平均半径约6,371公里，平均密度5.52g/cm3，是太阳系最大的一个岩石行星，也是太阳系所有天体中密度最高的。地球同时进行自转和公转运动，每自转一次为一太阳日（即一昼夜），每公转一周为一太阳年；地球自转的轨道面称为赤道面，公转轨道面称为黄道面，两者之间因转轴倾角产生的夹角称为黄赤交角，由此造成太阳直射点的纬度变化产生了四季的变化更替。作为标准行星，地球已完全独占邻近的轨道，在整个地球轨道上只在L4拉格朗日点的位置留有两个同轨道共振的地球特洛伊（2010 TK7和2020 XL5），但仍有大量近地天体可能会受地球引力影响而靠近甚至穿越地球轨道。地球仅有一顆真正意义上的天然卫星——月球，在其形成后不久就已被潮汐锁定；另外还有七个已知的越地小行星因公转周期与地球相近而被视作准卫星。
