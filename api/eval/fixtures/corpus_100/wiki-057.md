# 第二次世界大战

第二次世界大戰是1939年至1945年發生的全球軍事衝突，交戰雙方分為同盟國和軸心國，涉及彼時大多數國家。這場戰爭是歷史上規模最大的戰爭，導致6,000萬至7,500萬人死亡，其中上千萬人死於屠殺、飢荒、疾病和種族滅絕。戰爭末期，同盟國佔領德國、奧地利、日本和朝鮮等地，德日軍政領導人因戰爭罪受審。
