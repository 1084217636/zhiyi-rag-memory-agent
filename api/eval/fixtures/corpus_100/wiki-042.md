# 青藏高原

青藏高原，亦稱西藏高原、青康藏高原、海藏高原，是亚洲的高原地区，世界上最高的高原，平均海拔高度4500米，面积250万平方公里，有“世界屋脊”、“雪域高原”和“第三极”之称，是横跨中亚和東亚的巨大高原，其中主要位于中国西部的西藏自治区和青海省，以及在印度拉达克的一部分。它从南向北延伸1,000公里（620英里），从东到西延伸约2,500公里（1,600英里）。广义上的青藏高原除了自身外还包括横断山和喜马拉雅山，西起帕米尔高原，东至横断山脉东部，南至喜马拉雅山脉南缘，北至昆仑山‒祁连山北侧。涵蓋國境有中国西藏自治区、青海省全境、新疆维吾尔自治区、甘肃省、四川省、云南省部分，以及不丹、尼泊尔、拉达克、巴基斯坦、阿富汗、塔吉克斯坦、吉尔吉斯斯坦等地。
