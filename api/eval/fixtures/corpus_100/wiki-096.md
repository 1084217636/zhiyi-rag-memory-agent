# 氧

氧 是一種化學元素，化學符號为O，原子序數为8，在元素週期表中屬於氧族元素（16族或VI族）。作为一种非金屬，氧是具有高反應性的氧化劑，能夠與大部分元素结合形成化合物（氧化物）。氧在宇宙中的總質量在所有元素中位列第三，质量分数僅居氫和氦之下；氧也是地球地殼中最丰富的元素，地壳中近一半（46.6%）的質量也都是由氧化物（如水、二氧化碳、氧化铁、氧化硅等）所組成。
