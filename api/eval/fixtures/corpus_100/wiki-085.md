# 水浒传

《水滸傳》是一部以官話白話文寫成的章回小說，被列為中國四大名著與六才子書之一。關於其成書年代學界尚存爭議，目前主流觀點支持「明代嘉靖說」，推測約完成於1524年前後。該作品主要描寫北宋時期山東梁山泊以宋江為首的梁山好漢從被迫落草為寇、發展壯大，到接受朝廷招安並四處征戰的過程。該書在流傳過程中曾有《忠義水滸全傳》《江湖豪客傳》《水滸全傳》等不同名稱，現今普遍簡稱為《水滸》，其最終文本定型於明朝。
