# 内燃机

内燃機 是一種將燃料的化學能轉化為機械能的熱機，其主要特徵在於燃料與氧化劑（通常為空氣）的燃燒過程直接發生於引擎內部的燃燒室中，燃燒所產生的高溫高壓氣體同時充當工作介質，隨後氣體在高溫下迅速膨脹，對引擎的機械機構施加直接作用力，驅動活塞（往復式活塞引擎）、轉子（汪克爾轉子引擎）、渦輪葉片（燃氣渦輪發動機）產生位移，或透過噴嘴向後高速噴射（噴射引擎），從而輸出動力。
