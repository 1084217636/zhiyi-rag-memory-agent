# 三国演义

《三国演义》，全名《三國志通俗演义》，是成书于元末明初的长篇章回历史小说，作者一般归于罗贯中。作品叙事始于黃巾之亂，终于西晋统一，围绕曹魏、蜀汉与孙吴的兴亡展开。小说以陈寿《三国志》及裴松之注为主要历史依据，也吸收了《三国志平話》等通俗叙事，史实与文学虚构并存。《三国演义》通常被视为中国早期长篇历史演义小说的代表，并列入四大名著与四大奇書。
