# 唐朝

唐朝（618年6月18日—690年10月16日、705年3月3日—907年5月12日）是中国历史上的一個重要朝代，由唐高祖李淵所建立，國祚289年，历22任皇帝。唐朝首都在不同時期分別是长安（今陕西西安）和洛阳（今河南洛阳），陪都先後包括北都太原與其他都城。国号「唐」源自先秦時期的唐國，亦泛指今山西省的中心地域。唐朝前接隋朝，两者常合稱隋唐，為经历五胡乱华和南北朝分裂之后的大一统时期。
