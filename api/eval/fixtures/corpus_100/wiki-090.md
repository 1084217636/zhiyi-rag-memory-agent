# 论语

《論語》是中國春秋時期的思想家孔子言行為主的言論彙編，為儒家重要經典之一。《論語》的“論”读作「lún」，為論輯、編纂的意思，「語」是話語、言辭的意思，如《國語》、《新語》之類，合起來指言论的汇编。《漢書·藝文志》稱：「《論語》者，孔子應答弟子、時人，及弟子相與言而接聞於夫子之語也。當時弟子各有所記，夫子既卒，門人相與輯而論纂，故謂之《論語》。」
