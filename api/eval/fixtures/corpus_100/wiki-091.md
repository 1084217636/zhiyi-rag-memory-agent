# 元素周期表

元素週期表是依原子序數、核外電子排布情况和化学性质的相似性来排列化学元素的表格。一如其名，元素週期表的排列展现元素性质的週期性趋势。其中，週期表的横行被称作週期，纵列则被称作族。一般而言，在同一週期内，金属元素位于表的左端，非金属元素位于右端；同族的元素则大多具有相似化学性质。週期表中有四个族具有单独的别名，包括第1族（IA族）被称为碱金属、第2族（IIA族）被称为碱土金属、第17族（VIIA族）被称为卤素，以及第18族（VIIIA族）被称为稀有气体。
