# 文艺复兴

文藝復興 是歐洲發生於14至16世紀間的文化運動，發源自亚平宁半岛，而後散播至全歐各地。文藝復興上接中古時期、下啟近代歐洲之濫觴，人文主義風行，大眾逐漸相信人文價值較宗教為重要。各國文人對古希臘、古羅馬藝術及研究興致勃發，並開始欣賞周遭美好、篤信義理、質問現狀、挑戰舊有思想及教會信條。許多重要的科學發現及發明亦誕生於此時期。
