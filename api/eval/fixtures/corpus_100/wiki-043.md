# 南极洲

南极洲 是地球最南端的洲，位於南半球的南極區，为地理南极的所在地。南极洲大部分区域都在南極圈内，四周被南冰洋环绕。南极洲是世界上的第五大洲，其面积约为1,400万平方公里，約占地球陸地面積的十分之一，排在亞洲、非洲、北美洲和南美洲之後，是大洋洲的两倍。除了南极半岛最北端的部分区域之外，全洲約98%的地方都被平均厚度1.9公里的冰层覆盖着。
