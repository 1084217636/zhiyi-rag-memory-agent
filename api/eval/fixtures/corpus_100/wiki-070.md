# 公共卫生

公共卫生 已被定义为“预防疾病的科学和艺术”，它通过社会，组织（公共的和私人的），社区和个人的有组织的努力和明智的选择来延长寿命和提高生活品質。根据对人口健康的分析，及其所面临的威胁是公共卫生的基础。公众可能只有少数几个人，也可能只有一个村庄或整个城市；在大流行病的情况下，它可能包括在世界各大洲。 许多机构对健康的定义有所不同。 健康的概念考虑到了身体的，心理的，和社会的福祉，因此，根据联合国机构世界卫生组织的定义，这不仅仅是没有疾病或（障礙）。而且最近还成了人類日常生活的認識，認知和對醫療體系的價值觀。。
