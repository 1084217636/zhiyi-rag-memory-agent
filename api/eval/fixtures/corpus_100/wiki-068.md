# 细菌

細菌（学名：Bacteria）是生物的主要類群之一，屬於細菌域，过去曾经和古菌一起被归类在原核生物界，但已知古菌更接近真核生物，故原核生物界已被弃用。细菌是所有生物中數量最多的一類，據估計，其總數約有5×1030個。细菌是非常古老的生物，大约出现于37亿年前。真核生物细胞中的两种细胞器：线粒体和叶绿体，通常被认为是来源于内共生细菌。微生物无处不在，只要是有生命的地方，都会有微生物的存在。它们存在于人类呼吸的空气中，喝的水中，吃的食物中。细菌可以被气流从一个地方带到另一个地方。人体是大量细菌的栖息地；可以在皮肤表面、肠道、口腔、鼻子和其他身体部位找到。
