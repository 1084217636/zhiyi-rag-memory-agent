# 詹姆斯·克拉克·麦克斯韦

詹姆斯·克拉克·麦克斯韦 FRS FRSE，英国物理学家。其最大功绩是提出了将电、磁、光统归为电磁场现象的麦克斯韦方程组。麦克斯韦在电磁学领域的功绩实现了物理学自艾萨克·牛顿后的第二次统一。
