# 艾萨克·牛顿

艾萨克·牛顿爵士，英國博學家，身兼數學家、物理學家、天文學家、鍊金術士、神學家、作家與發明家等職。他是科学革命及其後啟蒙時代的核心人物，其著作《自然哲学的数学原理》 於1687年出版，不僅完成物理學史上首次重大理論統一，也奠定经典力学的基礎。牛頓在光学領域亦作出開創性貢獻，並與德國數學家戈特弗里德·莱布尼茨共同被視為微積分的創立者，儘管牛頓實際上早於萊布尼茲多年即已發展出微積分體系。除此之外，牛頓亦對科学方法的形成與完善有所貢獻，其學術成就普遍被認為對近代科學的誕生具有深遠影響。
