# 氮

氮 是一種化學元素，化學符號为N，原子序數为7。1772年，在丹尼尔·卢瑟福分離空氣後第一次被發現。雖然卡尔·威廉·舍勒及亨利·卡文迪什也在同一時間独立完成了相关研究，但因為盧瑟福更早公開發表而广受赞誉。1790年，法國化學家讓-安托萬·沙普塔提出了氮的命名nitrogène，因為氮存在于硝酸和硝酸鹽中。由于氮是窒息气体，安托万-洛朗·德·拉瓦锡提出了另一个命名azote，取自希腊语ἄζωτος，意思是“没有生命的”。这个名称被多数其它语言使用，例如法語、俄語等。
